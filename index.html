정당 · 숫자키로 선택

선택한 정당으로 선거구를 누르면 확정으로 칠해지고, 다시 누를 때마다 확정 → 유력 → 우세 → 경합우세 순으로 바뀌어요. 경합을 골라 누르면 비워져요.

의석수—❐✕

선거구 하나의 의석수는 '분할' 모드(또는 우클릭)에서 바꿔요. 처음 값은 TNO 지도의 의석수예요. '기본 의석수로'를 누르면 처음 값으로 돌아가요.

단축키—❐✕

F 칠하기 · S 분할 · D 비활성 · L 잠금
1~9 정당 선택 · 0 경합 · Ctrl+Z 되돌리기
비활성 선거구는 의석 합계에서 빠지고, 잠긴 선거구는 칠해지지 않아요.
